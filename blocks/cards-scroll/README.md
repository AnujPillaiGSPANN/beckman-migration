# cards-scroll

Custom **cards** block. Purpose: Single-row horizontal scroll strip: brochure covers with a hover "Download" overlay link, or application tiles (landscape image, red eyebrow, bold linked title).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: (1) image; (2) a single download link, or eyebrow paragraph + linked title.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
