# cards-product

Custom **cards** block. Purpose: linked product / service cards in a 3-column grid.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: two cells: (1) product image (contained, centered, not cropped), (2) title heading wrapping a link to the detail page, a description paragraph and a bulleted feature list; the title link makes the whole card clickable.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
