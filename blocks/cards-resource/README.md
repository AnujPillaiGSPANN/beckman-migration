# cards-resource

Custom **cards** block. Purpose: Wrapping 4/2/1 grid of document cards: bold title above a bordered cover thumbnail, red outline "Read" button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: (1) cover image (optionally linked); (2) bold title paragraph + "Read" link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
