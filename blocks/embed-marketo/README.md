# embed-marketo

Custom **embed** block. Purpose: Marketo-hosted form (forms2) rendered from the Beckman Marketo instance, red Submit button, single column on mobile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows: (1) Marketo base URL (https://pages.beckman.com); (2) Munchkin ID (682-XWP-826); (3) form ID (e.g. 3101).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
