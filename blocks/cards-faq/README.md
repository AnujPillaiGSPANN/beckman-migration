# cards-faq

Custom **cards** block. Purpose: static, always-open question/answer boxes stacked full width.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one cell: a question heading (bold) followed by one or more answer paragraphs (inline links allowed); no image.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
