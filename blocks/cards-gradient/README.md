# cards-gradient

Custom **cards** block. Purpose: 2x2 grid of grey text cards with a 4px red-to-purple gradient top border, heading, text and a right-aligned red outline button; hover lift.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card, one rich text cell `text`: heading (h3) + paragraph(s) + em-wrapped link (outline button).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
