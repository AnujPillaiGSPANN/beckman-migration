# hero-video

Custom **hero** block. Purpose: Full-width hero with a muted, looping Wistia background video (no controls) under a dark overlay, a centered H1 and pill CTAs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows: (1) Wistia video URL, optional poster image; (2) H1 + CTA links (bold links render as buttons).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
