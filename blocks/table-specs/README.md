# table-specs

Custom **table** block. Purpose: Plain two-column specification table: centered, red header underline, grey row rules, vertical column divider.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows of [specification | description]; the first row is the header (Specifications | Description); values may be bulleted lists.

## Supported variations

No variations.
