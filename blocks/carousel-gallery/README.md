# carousel-gallery

Custom **carousel** block. Purpose: Product image gallery: one large image at a time, prev/next chevrons, clickable thumbnail strip generated from the slides.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per image: (1) image; (2) optional caption.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
