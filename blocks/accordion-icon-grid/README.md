# accordion-icon-grid

Custom **accordion** block. Purpose: Row of grey icon tiles (4/2/1 per row) that reveal their bullet lists below the tiles, red chevron indicator. As on the source (all tiles share one toggle function), clicking any tile opens or closes every tile of the block together, with a 500ms ease-out max-height transition.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: (1) icon image + title text; (2) content (bulleted list).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
