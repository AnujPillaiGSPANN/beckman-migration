# carousel-product

Custom **carousel** block. Purpose: Multi-card slider of white bordered product cards with prev/next arrows (5/3/2/1 visible); arrows hide when all cards fit.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card, same cells as cards-product: (1) image (optionally linked); (2) linked title heading + description / list.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
